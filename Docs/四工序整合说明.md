# 原料工坊：四工序整合说明

依据：用户在对话中提供的知乎文章截图，第 5—8 步。原链接：https://zhuanlan.zhihu.com/p/633981318 。本次已直接核对截图；此前无法访问网页的推测不作为依据。

## 工序与材料

| 原文工序 | 本工序处理材料 | 操作与产物 | 去向 |
| --- | --- | --- | --- |
| 05 筛洗 | 瓷石块 | 用竹筛在浅水中清洗、去杂，保留净石 | 送入碓臼 |
| 06 舂石 | 筛洗后的净石 | 引水驱动水碓，将石块击成石粉 | 石粉入淘洗池 |
| 07 淘洗 | 舂后石粉 | 浸水后用泥耙反复淘洗、分出粗渣，淘成粗泥 | 粗泥送过筛；粗渣返回碓臼再舂 |
| 08 过筛 | 淘洗后的粗泥 | 上筛、摇筛，细料随浆水进入沉淀池，截留并清除细渣 | 本段体验结束于过筛入池 |

05 筛洗不是对泥浆过滤。07 淘洗采用泥耙，粗渣返舂属于循环利用；08 的细渣另置。截图的 09 制浆不属于这四道工序；本次没有添加“再次筛洗泥浆”或“撇水成泥”的结尾。

## 运行

1. 打开 `Assets/Scenes/PorcelainJourney.unity`，或使用 Unity 菜单「瓷从泥生 → 整合工坊 → 1 · 打开四工序场景」。
2. 按 Play，先阅读学徒任务书，再点击「开始 / 返回工坊」。
3. 四工位从左到右依次排列，沿前方宽通道行走。靠近当前目标 5 米内按 F，就会到达器具前的操作位并对准；按住 E 即可操作，也可按住左键配合鼠标摇洗或耙洗。
4. 按 R 清理过筛细渣；Tab / J 查看任务书；Esc 打开暂停菜单。菜单中的「画面与操作」提供清晰/流畅画质、原生分辨率、视角与灵敏度选项。暂停菜单也可返回起点并保留进度，或确认重新开始。

按 05 → 06 → 07 → 08 依次推进。07 中有一轮教学返舂：粗渣运回第一只碓臼，开闸舂打、关闸停稳、取粉回池，再淘洗成粗泥。此时任务书仍归于 07，保留原文工序关系。工序次数和操作时长为教学压缩。

## 一字排布与清晰画面

四站中心依次位于 X=3、11、21、28 米，主操作面朝向同一条通道。原小房间由长工坊替换，轮轴、水轮、双碓作为完整机构旋转搬移；水闸移到工位前侧，后方保留水道。碓未停稳时隔离碓臼前沿，关闸停稳后开放取粉位置。

默认采用完整纹理、16 倍各向异性过滤、4 倍 MSAA 与 100% 渲染比例；关闭动态分辨率，程序化材质从 256 提升至 512 像素，减弱镜头晃动。进入播放时尝试关闭 Game 视图低分辨率预览，并设为 1x；也可使用菜单「瓷从泥生 → 整合工坊 → 5 · 清晰 Game 视图（1x）」。编辑器预览的真实分辨率随 Game 面板大小变化；打包运行可使用屏幕原生分辨率。

最新排布验证（2026-11-21）：四站按 05—08 从左到右展开；33 米前方通道连续可走，17 个目标均通过正面射线命中和 F 就位检查。已重新跑通全部工序及返舂回池，运行错误 0。报告见 JourneyValidation/playthrough-report.txt；layout 预览采用去屋顶的剖视方式，仅为查看空间排布，游玩时保留屋顶。

## 物料交接显示

取走任一碓臼的石粉后，对应的原地交接桶清空并隐藏，物料随手持桶显示；两臼均取完才允许进入送粉步骤。返舂时只为第一只碓臼备空桶，放入的粗渣显示为粉堆，舂细后不会残留石块；再次取粉后原地桶也清空隐藏。

从淘洗池取出粗渣时，池中其余泥浆继续保留，原地返舂桶随搬运隐藏。收取整批淘洗粗泥后，清空池内液面、粉堆、粗渣和沉积物。验证入口已加入上述显示状态检查，并在 `JourneyValidation/material-*.png` 保存交接、返舂和清槽截图。
