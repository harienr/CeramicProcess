# 工序 05 · 筛洗 —— 场景与玩法设计

> 归属：《瓷从泥生》· 景德镇传统制瓷 · 第一阶段「原料制备」
> 依据：《美术风格 AI 提示词》第 1–7 节
> 状态：可运行原型（程序化占位美术）；设备结构与工序编号依据**待核实**

---

## 1. 这一步在做什么

筛洗是把「已经舂碎、泡开的粗浆」变成「可用的细腻泥料」的分离工序。

浆料倒上筛面后，细颗粒随水穿过筛网落入缸中，粗颗粒（石英粗粒、未解理的瓷石屑）留在筛面。
筛面积渣到一定程度会堵死网眼，必须用竹刮把粗渣拨走。落入缸中的细浆静置后分层，
上层清水要撇掉，下层才是能进入下一步的泥料。

一道工序里有三次材料状态变化，这也是玩法的三条反馈主线：

| 阶段 | 材料状态变化 | 玩家能"看见"什么 |
| --- | --- | --- |
| 上筛 | 粗浆 → 筛面湿浆 | 浆层在筛面铺开、筛网变湿变深 |
| 搅洗 | 湿浆 → 细浆 + 粗渣 | 浆层变薄、缸内细浆上涨、筛面渣层变厚 |
| 静置撇水 | 细浆 → 泥料 + 清水 | 缸内分层、清水层被撇低、露出泥面 |

## 2. 场景

### 2.1 空间与材料流向

一个 6.4 × 5.8 m、层高 3.1 m 的连贯工坊，四个操作点沿"原料 → 成品"的路径布置，
玩家从门口进入，沿逆时针走一圈就完成一次循环。

```
                      后墙（工作台）
   ┌──────────────────────────────────────────────┐
   │  原料袋      [粗浆缸]   [渣盘]   [清水缸]      │
   │   ○           ▣          ▤         ▣    木架  │
   │                                              │
   │  木凳            ╔══════════╗                │
   │                  ║  筛架    ║  ← 竹筛        │
   │                  ║  ┌────┐  ║                │
   │                  ║  │沉淀│  ║  ← 承接细浆    │
   │                  ║  │ 缸 │  ║                │
   │                  ║  └────┘  ║                │
   │                  ╚══════════╝                │
   │                                              │
   │          ▭ 窗（自然侧光）        ○ 备用竹筛   │
   └──────────────────────────────────────────────┘
                        ↑ 门（玩家进入）
```

- **取浆点**（左）：粗浆缸 + 木瓢
- **筛洗点**（中）：筛架 / 竹筛 / 正下方沉淀缸 ← 主操作区
- **清渣点**（右）：粗渣盘 + 竹刮
- **撇水点**（中下）：沉淀缸水面 + 撇水勺

材料流向一眼可读：粗浆在左、筛在中间、细浆落进正下方的缸、粗渣进右边的盘。

### 2.2 场景物件清单

| 物件 | 数量 | 作用 | 备注 |
| --- | --- | --- | --- |
| 工作台（3.6×0.85×0.8 m） | 1 | 承放三个容器 | 旧木褐，台面有使用痕迹 |
| 原木桶（粗浆缸 / 清水缸） | 2 | 原料与稀释用水 | 两道铁箍，桶壁有水痕 |
| 大陶缸（沉淀缸） | 1 | 承接细浆、静置分层 | 未上釉，哑光 |
| 竹筛 + 筛架 | 1 | 主操作面 | 筛网可透视，湿态变深 |
| 木盘（粗渣盘） | 1 | 承接粗渣 | 渣堆随存量长高 |
| 木瓢 / 竹刮 / 撇水勺 | 各 1 | 三种工具 | 轮廓区分明确 |
| 木凳 / 原料袋 / 木架 / 陶罐 / 备用竹筛 | 各若干 | 环境叙事 | 说明原料从哪来 |

### 2.3 光照与镜头

- 主光：左侧窗洞进入的柔和天光（方向光，软阴影，暖中性）。
- 补光：窗口一盏漫射点光 + 工作区上方一盏低强度暖光，保证暗部仍能看清工具。
- 反射：室内一盏实时反射探针，桌面与水面有**局部**柔和反光。
- 无泛光、无景深、无夸张粒子。
- 第一人称站立视角，FOV 58°；操作时仅轻微前倾 + 视线稳定，不做大幅镜头运动。

## 3. 玩法

### 3.1 循环

```
  ┌─ 取粗浆（木瓢） ──→ 上筛（倒浆） ──→ 徒手搅洗 ──┐
  │                                                  │
  │            筛面积渣 ≥ 阈值                       │
  │                  ↓                               │
  │            清渣（竹刮 → 渣盘） ──────────────────┤
  │                                                  │
  │        细浆量达到沉淀目标                        │
  │                  ↓                               │
  └── 静置（按 T，时间跳转） → 撇水（撇水勺） → 完成 ┘
```

一次完整流程约 **4–6 分钟**：约 5 次上筛、2 次清渣、1 次静置、1 次撇水。

### 3.2 操作

| 输入 | 行为 |
| --- | --- |
| WASD / Shift | 移动 / 放慢 |
| 鼠标 | 观察 |
| 左键 | 拾起工具；按住执行当前动作（舀 / 倒 / 搅 / 刮 / 撇） |
| 右键 / Q | 放下手中工具 |
| T | 静置沉淀（时间跳转） |
| Ctrl + R | 重来 |
| Esc | 释放鼠标 |

### 3.3 每个动作的判定

**取浆**：手持木瓢，按住左键。瓢内浆量以 2.4/s 上升；一满瓢 = 整批原料的 20%。
瓢里装的东西会在瓢口按液面高度显示（浆是灰白、水是淡青），不会混淆。

**上筛**：手持木瓢，按住左键在筛面上方倾倒。筛面湿浆超过容量（0.62）时溢出的部分计入损耗。

**搅洗**：**空手**按住左键在筛面画圈。

- 强度由鼠标移动速度决定（40 → 300 单位/秒映射到 0 → 1）。
- 画圈比来回晃更有效：持续同一旋转方向时给出最多 +40% 的效率（角度一致性判定）。
- 太快（> 2100 单位/秒）会把浆甩出筛沿，溅出的部分直接算损耗，并在屏幕下方提示。
- 浆料越稠越慢：稀释度 0 时只有 52% 效率，所以**先舀一瓢清水加进去**是最优解。
- 每次搅洗把 58% 的浆料变成细浆进缸，42% 变成粗渣留在筛面。

**清渣**：手持竹刮，按住左键左右拖动。刮动速度越快越有效。
筛面渣量达到阈值（0.26）时，筛面完全堵死、搅洗效率归零——必须清渣才能继续。
这是本工序唯一的"强制维护"环节，也是节奏的呼吸点。

**静置**：细浆达到目标后，按 T。屏幕以米白遮罩明示「静置 一时辰」，
2.8 秒后缸内分层（下层泥、上层清水）。**不做假装实时的等待。**

**撇水**：手持撇水勺，按住左键左右撇动。清水层被逐步撇低（0.34 → 0）。
撇过界（水面见底后继续）会带走泥料，计入损耗。

### 3.4 反馈优先级

遵循规范「成功反馈优先展示材料状态变化，再补充简短文字」：

1. 筛面浆层缩小、筛网由深变浅、缸内细浆上涨、渣层变厚 —— 先看见变化
2. 「材料状态」面板的细线进度 —— 后确认数值
3. 屏幕下方一句短提示 —— 最后补充说明

面板在 3.5 秒无变化后自动淡到 30%，不长期遮挡材料与双手。

### 3.5 评分

| 指标 | 算法 | 说明 |
| --- | --- | --- |
| 细腻度 | 纯度 × 0.8 + 稀释合理度 × 0.2 | 未清渣就上浆会让粗渣混入，拉低纯度 |
| 回收率 | 实际入缸细浆 / 理论可用细浆 | 搅洗不彻底会拉低回收率 |
| 损耗 | 溅出 + 撇水过界 | 动作粗暴的代价 |
| 评级 | 加权后 ≥0.86 优 / ≥0.70 良 / 其余 可 | 结算面板展示 |

结算面板同时标注「设备结构与工序编号依据待核实」，符合规范对未确认内容的要求。

## 6. 运行方式

1. 菜单 **瓷从泥生 → 1 · 打开筛洗场景并运行**（或直接打开 `Assets/Scenes/SieveWash.unity` 后按 Play）。
2. 场景里只有一个「瓷从泥生 · 筛洗工坊」，进入 Play 时才生成房间、道具、玩家与界面。
   这样做是为了在没有正式美术资源时先跑通玩法与观感。
3. 如果要出包：先执行 **瓷从泥生 → 3 · 将筛洗场景加入 Build Settings**。

> 注意：`Assets/Resources/Shaders` 下的四个着色器必须保留。运行时代码按名字从这里加载，
> 移到别处会导致回退到 Standard、丢失筛网挖孔与水面效果。

## 7. 调参速查

调整手感只需改 `SieveWashProcess` 上的字段（已标注单位与含义）：

| 字段 | 默认 | 作用 |
| --- | --- | --- |
| `ladleCapacity` | 0.20 | 一满瓢占整批的比例 |
| `sieveCapacity` | 0.62 | 筛面容量，超出即溢出 |
| `clogThreshold` | 0.26 | 多厚的渣会彻底堵死筛面 |
| `settleTarget` | 0.42 | 沉淀缸达到多少可静置 |
| `fineShare` | 0.58 | 浆料中细颗粒比例 |
| `washBaseRate` | 0.055 | 搅洗基础速率 |
| `scrapeRate` | 0.42 | 刮渣速率 |
| `decantRate` | 0.15 | 撇水速率 |
| `splashSpeed` | 2100 | 开始溅出的鼠标速度 |

角色手感在 `FirstPersonController`（步速 1.45 m/s、加速 11、起伏 1.1 cm）。

## 8. 待核实（按规范须显式标注）

1. **工序编号**：本项目把筛洗编为第五步，编号依据尚待与资料核对；代码与界面均把编号作为可替换的显示值。
2. **设备结构**：筛架的形制、筛网材质（马尾筛 / 绢筛 / 铜丝筛）、沉淀缸尺寸与埋置方式均为中性占位设计。
3. **是否分缸**：传统工序中"淘洗—过筛—沉淀"可能在不同池缸中完成，当前简化为「筛下直接入沉淀缸」。
4. **时间跳转时长**："一时辰"为示意，实际静置时长随浆料浓度与气温变化。

## 9. 后续美术替换路径

当前所有物件都是程序化占位，替换时按下列顺序收益最大：

1. **竹筛与筛网**（玩家注视时间最长）——做成真实编织几何 + 法线，可复用 `SieveCloth` 的湿态参数。
2. **工具三件**（瓢 / 刮 / 勺）——保留现有 `ToolItem` 的持握姿态字段即可直接换模型。
3. **沉淀缸与木桶**——换成带真实内壁厚度与手作痕迹的模型。
4. **手部**——目前是掌 + 指团 + 拇指 + 袖口的占位，可直接换成绑定手模。
5. **环境**——梁、窗、架、袋，最后替换；它们只承担氛围。

### 可直接用于概念图 / 资产制作的提示词

**场景总览**

> 半写实三维，景德镇传统制瓷工坊内的筛洗工序。紧凑的 6×6 米木构工坊，米白灰墙、泥灰石地、旧木褐梁柱。
> 左侧大窗透入柔和自然侧光，光束落在石地上。房间中央一座木制筛架，架上放着一面竹筛，
> 筛下正对一口哑光大陶缸。后方长木台上并排放着两只原木桶与一个木渣盘。所有器物低饱和、比例真实、
> 边缘有长期使用的磨损。无人物，无装饰纹样。青花蓝仅出现在极少量工序标识上。

**筛面特写**

> 竹筛的篾圈与绷紧的细筛网，筛面上残留一层灰白色、不透明的湿泥浆，浆层边缘正在变干、
> 中间还有搅动留下的同心痕迹。网眼被细泥填住一部分，局部露出粗颗粒。
> 侧光从左上过来，湿泥只有柔和的局部反光，不是镜面。背景虚化到工坊暗部。

**工具三件**

> 同一套低饱和木作与竹作工具：一只小木瓢（碗形瓢头、斜出木柄，柄身被手磨亮）、
> 一片扁平竹刮（刃口渐薄、握把加厚）、一把浅口宽勺（专门撇水）。
> 灰白木色与旧竹黄，接触面有磨损，作用部位轮廓清楚。纯色浅灰背景，棚拍柔光。

**静置分层**

> 一口大陶缸的俯视近景。缸内泥浆已经静置分层：上层是一层半透明的清水，
> 下层是灰白色的细腻泥料，两层的分界线清晰。水面有极轻微的涟漪与柔和反光。
> 陶缸内壁未上釉，哑光，有水痕。冷白侧光，无高光溢出。
